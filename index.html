Scratch Programming

Scratch

Pemrograman Visual Koding untuk Anak

Buka Editor

Langkah Praktis Belajar Scratch:

  1. 1
    Buka Web Editor Scratch Klik tombol "Buka Editor" di atas untuk masuk langsung ke lembar kerja Scratch secara online.
  2. 2
    Pilih Karakter (Sprite) & Latar (Backdrop) Klik ikon Kucing di kanan bawah untuk menambah karakter baru, serta ikon gambar untuk mengganti panggung/latar belakang.
  3. 3
    Susun Blok Pemrograman Tarik blok warna kuning "When Green Flag Clicked" dari panel Events, lalu hubungkan blok gerakan (Motion) atau suara (Sound) di bawahnya.
  4. 4
    Uji Coba & Simpan Proyek Klik Bendera Hijau untuk menjalankan animasi/game buatanmu, lalu simpan file melalui menu File > Save to your computer.

Canva Design

Canva

Desain Grafis & Presentasi Komputer

Buka Canva

Langkah Praktis Belajar Canva:

  1. 1
    Masuk ke Canva Studio Klik tombol "Buka Canva" di atas untuk memulai sesi pembuatan karya grafis interaktif.
  2. 2
    Pilih Jenis Desain Pilih jenis lembar kerja seperti Presentasi, Poster, atau Infografis sesuai petunjuk tugas dari Guru TIK.
  3. 3
    Edit Teks, Gambar & Elemen Gunakan bilah menu sebelah kiri untuk menyisipkan teks judul, stiker animasi, bentuk geometris, serta foto pendukung.
  4. 4
    Unduh & Bagikan Hasil Karya Klik tombol Bagikan (Share) > Unduh (Download) lalu pilih format PDF Standard atau Gambar (PNG/JPG) untuk diserahkan ke Guru.
